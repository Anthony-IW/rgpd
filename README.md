# RGPD Audit Master

J'ai besoin, pour ma société "Informatique & Web" (dont le logo et ci-joint), une application de gestion d'audit RGPD. Le but est d'avoir l'application la plus complète possible afin que je puisse aller dans les entreprises pour les auditer sur la partie RGPD. Insère vraiment toutes les fonctionnalités afin que l'audit puisse être complet. cela doit concerner tous les domaines, toutes les acquisitions de contact, toutes les sécurités etc...
Il doit y avoir la possibilité d'enregistrer les entreprises dans lesquelles je vais intervenir, et la gestion et suivi d'audit, du debut jusqu'à la fin, pour chaque entreprise.
Je te laisse développer tout ça avec tout ce qu'il faut et toutes les connaissances que tu as sur le sujet. je veux l'application la plus complète du monde
